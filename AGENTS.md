# OperaConnect Web

This repository contains the web application. The mobile Expo/React Native application will be maintained separately.

## Stack
- React + TypeScript
- Vite
- CSS (no UI framework unless explicitly agreed)

## Guidelines
- Build responsive, accessible interfaces with semantic HTML.
- Keep components small and separate reusable UI from page-level composition.
- Use Spanish as the initial interface language; keep copy easy to internationalize.
- Visual direction: light, editorial, elegant, contemporary; avoid generic SaaS styling.
- Run `npm run build` before declaring implementation complete.
- Do not add backend integrations until the product flow and data model are agreed.
