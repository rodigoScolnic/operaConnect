# OperaConnect Web

Plataforma web para conectar cantantes líricos independientes con teatros, compañías y profesionales de casting.

## Stack
- React
- TypeScript
- Vite
- CSS

## Requisitos
- Node.js 20.19+ o 22.12+

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

La aplicación móvil tendrá su propio repositorio. Este repositorio está dedicado a la experiencia web.
